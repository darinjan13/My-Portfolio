# Darin Jan Soriano | Full-Stack Portfolio

A high-performance, technical portfolio template featuring a **Cyberpunk/Brutalist** aesthetic. Built with React 19, TypeScript, and Tailwind CSS, this portfolio is designed to showcase complex technical expertise in Full-Stack development, AI integration, and IoT systems.

## ✨ Core Features

-   **Interactive Terminal:** A functional CLI-style component allowing users to explore system stats, social nodes, and project data via commands.
-   **Technical Aesthetic:** Diagnostic-style corner marks, scanline overlays, glassmorphism, and a high-contrast "Surface Dark" & "Brand Primary" color palette.
-   **Hardware-Software Convergence:** Dedicated sections for IoT and AI-driven projects.
-   **Magnetic Interactions:** Custom magnetic button components for an extra layer of tactile feedback.
-   **Optimized Performance:** Built with Vite for ultra-fast HMR and build times.
-   **Connected Contact Form:** Integrated with EmailJS for direct client communication without a complex backend.

## 🛠️ Tech Stack

-   **Frontend:** React 19, Vite, TypeScript
-   **Styling:** Tailwind CSS (Modern v4 utility-first approach)
-   **Animations:** Motion (formerly Framer Motion) for smooth, logic-driven transitions
-   **Icons:** Lucide React
-   **Communication:** EmailJS for client-side email delivery

## ✨ Design & Experience

This portfolio is built on the philosophy of **"Hardware-Software Convergence."** It moves away from generic, flat UI in favor of a diagnostic, technical aesthetic that reflects the intricate nature of full-stack engineering.

### Key Visual Pillars:
- **Diagnostic Aesthetic:** Utilizing "diagnostic corners," scanline overlays, and monospace typography to give the interface a "system readout" feel.
- **Interactive Terminal:** A fully functional bash-inspired terminal component (system_status.sh) that allows visitors to query personal data, social links, and skills through a text-based interface.
- **Micro-Interactions:** Custom "Magnetic" components and high-refresh-rate animations powered by Motion to create a tactile, responsive user experience.
- **Cyber-Industrial Palette:** A curated "Surface Dark" background with high-contrast "Brand Primary" (Neo-Mint) accents, optimized for readability and a modern tech vibe.

## 🛠️ Core Modules

- **System Profile:** An "about" section that treats personal history as a system entry, featuring custom image overlays and origin telemetry.
- **Tech Ecosystem:** A showcase of specialized stacks including AI Integration, Full-Stack Architecture, and IoT Solutions.
- **Dynamic Projects:** A horizontal-scroll inspired project gallery with detailed status indicators and category tagging.
- **Encryption-Ready Contact:** A sleek communication portal that simplifies complex inquiry transmissions.

## ⚙️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4 (Modern utility-first approach)
- **Motion:** Motion (Framer) for transition logic
- **Infrastructure:** Integrated with EmailJS for serverless communication
